# 👨‍💻 About Me

I'm a Software Engineer passionate about designing reliable, scalable, and maintainable software systems.

My professional background is rooted in **backend development**, where I've spent years designing production systems using **Java/Spring**, **Python/FastAPI**, and **PHP/Laravel**. Alongside commercial software development, I enjoy solving challenging engineering problems spanning robotics, distributed systems, networking, embedded software, artificial intelligence, and cybersecurity.

I graduated with a Bachelor's degree in **Cybersecurity** at the Czech Technical University in Prague and am currently pursuing a **Master's degree in Quantum Informatics**, expanding my knowledge in quantum computing, advanced mathematics, and next-generation computational technologies.

I enjoy building systems that connect software with the real world—from enterprise web applications to autonomous robots and embedded devices.
